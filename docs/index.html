Security Enforcement & Dual-Mode Network Model

Exposing personal cloud storage to the internet via Cloudflare Tunnel requires robust network boundaries and strict access isolation. Nextcloud Server for Windows enforces layered zero-trust protection across all services:

Loopback-Only Supervisor Binding
The supervisor daemon and control API (/api/*) bind strictly to 127.0.0.1. They are completely inaccessible from public interfaces and network adapters.
DNS Rebinding & Host Validation
Every incoming HTTP request to the supervisor validates the Host header. External or spoofed host headers are immediately rejected with 403 Forbidden.
CSRF & Cross-Origin API Protection
API mutation requests (POST /api/*) verify the Origin header. Third-party websites loaded in the user's browser cannot manipulate daemon settings.
Caddy Reverse Proxy Isolation
Caddy blocks all internal supervisor API paths (@forbidden) and denies external access to /_dashboard* (@external_dashboard 403) over Cloudflare Tunnel.
Dual-Mode Cloudflare & Localhost Routing
Nextcloud auto-detects request origin: activates HTTPS overwrite and client IP trust (HTTP_CF_CONNECTING_IP) over Cloudflare, while serving clean HTTP on http://localhost:8080 locally.
Atomic Hot Database Backups
Point-in-time database snapshots (VACUUM INTO) create consistent live SQLite backups on demand without locking the database or interrupting active file synchronizations.

Quick Start (Windows 10, 11, or Server 2019+)
  1. Download nextcloud-windows-aio-v1.0.0-portable-x64.zip from GitHub Releases.
  2. Extract the archive into any directory (e.g. C:\NextcloudAIO).
  3. Double-click nextcloud-aio.exe to start the stack and open the desktop management dashboard.
  4. In the dashboard, paste your Cloudflare Tunnel token or access directly via http://localhost:8080.
  5. Default administrator account is initialized automatically (admin / NextcloudAdmin2026!). Update your credentials immediately via the Config view.
